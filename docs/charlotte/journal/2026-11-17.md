## Problèmes et solutions

- **La page ouverte en double-clic ne charge pas les modules JS** : en `file://`, le navigateur bloque `import`/`export`. Solution : des `<script>` classiques et un objet global, avec `module.exports` pour les tests Node.
- **Pas de son au premier essai** : le navigateur bloque le son tant qu'on n'a pas cliqué. Solution : créer l'`AudioContext` au clic sur « Démarrer ».
- **L'eau du verre paraissait délavée** : le verre semi-transparent était dessiné par-dessus l'eau. Solution : verre presque transparent (opacité 0,12).
- **Le nuage blanc ne se voyait pas sur la carte blanche** : manque de contraste. Solution : fond de ciel bleu derrière le dessin.
- **Impossible de changer vraiment d'onglet en Chrome headless pour tester** : pas de second onglet visible. Solution : redéfinir `document.hidden` et envoyer l'événement `visibilitychange` à la main dans le script de test.
